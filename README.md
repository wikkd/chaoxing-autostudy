# 超星学习通网课辅助 · Chaoxing AutoStudy

[chaoxing.com](https://www.chaoxing.com)（超星学习通）**自动刷视频课**的用户脚本（UserScript）。
以 **MIT 协议**开源，源码与构建流程完全公开。

> ⚠️ 本脚本仅供**计算机自动化技术交流与学习**。请在遵守平台规则与当地法律的前提下使用；
> 刷完课建议自行复习。使用风险请自行承担。

> 本项目由 [xinwei-autostudy](https://github.com/wikkd/xinwei-autostudy)（芯位版）拆分而来，v1.1.0 起专注纯刷课，不含答题功能。

---

## 功能

- **自动刷课**：穿透同源 iframe 驱动视频播放（点「播放视频」大按钮、静音、合成鼠标移动防失焦暂停），播完 ≥92% 自动点「下一节」。
- **视频倍速**（默认 1x）：面板可选 1 / 1.25 / 1.5 / 2x（平台上限）。改播放速度有风控风险，请自行斟酌。
- **风控告警**：触发风控验证码（9010）时面板告警提示人工输入，不代答不绕过；单视频串行启动降低触发概率。
- **异常自愈**：平台弹出「学习状态异常」时自动刷新页面续跑。
- **悬浮控制面板**：刷课开关、倍速选择、实时进度与日志；位置与最小化状态自动记忆。

## 安装

1. 安装油猴类扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat](https://scriptcat.org/)。
2. 获取脚本：
   - 开发版：仓库 `dist/chaoxing-autostudy.user.js`，直接拖入扩展安装；或
   - 自行构建（见下）。
3. 打开 `i.chaoxing.com`（超星学生端）任意课程学习页，左上角出现控制面板即生效。

## 构建（从源码）

源码按模块拆分在 `src/`，通过 `build.js` 拼接为单一用户脚本（共享同一 IIFE 作用域）。
构建时会自动剥离整行注释并折叠空行（模板字符串内容原样保留），发布版体积更小、源码保持可读。

```bash
node build.js          # 生成 dist/chaoxing-autostudy.user.js
node build.js --watch  # 监听 src/ 变化自动重建（需手动刷新浏览器）
```

目录结构：

```
src/
  meta.js       用户脚本元数据头（==UserScript==）
  config.js     全局配置 CFG / 持久化键 / loadCfg
  utils.js      可见性判定、DOM 小工具、静音
  sites.js      超星适配层：CX（视频穿透/章节跳转/倍速/风控告警）
  log.js        面板运行日志与进度条
  ui.js         控制面板 UI（CSS / DOM / 拖动 / 位置记忆 / 事件绑定）
  autoplay.js   挂机主循环（驱动 CX.tick）
  popup.js      学习状态异常弹窗自动刷新
  bootstrap.js  入口：防重复注入、视频 iframe 注入、挂载 UI、启动
build.js        拼接 + 发布版瘦身
dist/           构建产物
```

## 配置

控制面板「⚙ 挂机」页：

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 全自动刷课 | 开启后自动播放视频并逐节推进 | 关 |
| 视频倍速 | 1 / 1.25 / 1.5 / 2x（风险项，>1x 有风控可能） | `1x` |
| 静音 | 视频默认静音，可开启声音 | 静音 |
